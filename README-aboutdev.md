# About page — `aboutdev`

This branch adds a dedicated `/about` destination for the storefront. The existing homepage About section remains the business/trust summary and now points visitors to the richer About page.

## What is included

- Dedicated TanStack Start file route at `src/routes/about.tsx`.
- Sharplink-inspired editorial layout: oversized typography, layered hero treatment, subtle floating artwork, marquee stack and reveal-on-scroll sections.
- Existing `ScrollReveal` is reused, so the implementation respects `prefers-reduced-motion` instead of introducing a second animation framework.
- Client-side GitHub public-profile fetch for `Shubhampatidar007` with safe fallbacks.
- Social profile grid for GitHub, Instagram and LinkedIn.
- Editable About profile fields: name, role, bio and contact.
- Personal photo upload with local-browser persistence for this first version.
- Technology/brand names are shown as lightweight badges; no third-party brand asset files are required.

## Important repo-specific notes

This project is TanStack Start with file-based routes. `src/routes/README.md` documents `src/routes/about.tsx` as `/about`. The generated `src/routeTree.gen.ts` is owned by TanStack Router and should be regenerated by the normal development/build workflow rather than hand-edited.

The current storefront navigation previously pointed About to `/#about`; `src/data/navigation.ts` now points it to `/about`. The homepage About content in `src/components/home/AboutSection.tsx` also provides a dedicated About CTA.

## Branch workflow

The feature branch was created from `main` as `aboutdev`.

```bash
git checkout main

git checkout -b aboutdev
```

After pulling the existing branch from GitHub, continue with normal feature work:

```bash
git add src/ README-aboutdev.md
git commit -m "feat: add sharplink-inspired about page"
git push -u origin aboutdev
```

## Image replacement

The current hero artwork is generated with CSS gradients/grid shapes so there is no stock-image dependency. The profile image can be replaced through the upload control. For a production admin workflow, move the uploaded photo from local browser storage to your existing Supabase Storage and store the public URL in the admin profile record.

## Social API limitation

GitHub is fetched directly from its public API. Instagram and LinkedIn are intentionally represented as links rather than scraped client-side profiles. A real API integration can be added later without changing the visual component contract.
