# About page — `aboutdev`

Adds a dedicated `/about` destination for the storefront while keeping the homepage About section focused on trust/business information.

## Included

- Dedicated TanStack Start file route at `src/routes/about.tsx`.
- Sharplink-inspired visual direction: oversized typography, layered hero, scroll-linked parallax, pinned desktop profile image, staggered section reveals, horizontal technology movement and editorial spacing.
- GSAP `ScrollTrigger` drives the About-page motion without replacing the rest of the app's existing motion system.
- Responsive GSAP behavior: desktop gets the richer pinned/parallax treatment; mobile keeps lighter scroll effects and avoids pinning.
- `prefers-reduced-motion` disables GSAP movement and continuous decorative animation.
- Client-side GitHub public profile fetch for `Shubhampatidar007` with safe fallbacks.
- GitHub, Instagram and LinkedIn profile links with accessible icons.
- Editable About fields: name, role, bio and contact.
- Personal photo upload with browser-local first implementation.
- CSS-generated hero artwork, so no personal stock image is baked into the repo.

## Animation dependency

GSAP is declared in `package.json` as `^3.15.0`. ScrollTrigger is included in the GSAP package and registered in `src/components/about/AboutSection.tsx`. GSAP 3.15.0 is the current npm release at the time of this implementation, and ScrollTrigger supports scrub, pin and scroll-triggered timelines. See the official GSAP docs for installation and ScrollTrigger usage.

After pulling this branch, install dependencies so your local `package-lock.json` is updated consistently:

```bash
npm install
```

Do not add a second animation library just for the About page.

## Repository integration

This repository is TanStack Start with file-based routing. `src/routes/about.tsx` maps to `/about`; `src/routes/README.md` documents that convention. `src/routeTree.gen.ts` is generated by TanStack Router and should be regenerated by the normal development/build workflow when route files change.

The storefront About navigation now points to `/about`. The existing homepage About section remains intact and has a CTA to the full page.

The global `SmoothScroll` text-reveal observer skips `.about-page` so Motion and GSAP do not compete for the same transform/opacity properties.

## Photo replacement

The profile upload stores a Data URL in browser local storage for this first version. For production, move this upload to Supabase Storage and persist only its URL in the authenticated admin profile record.

## Hero image replacement

The hero is currently CSS artwork rather than a stock/personal image. Replace the CSS artwork later with a real business/personal hero image without changing the animation hooks or page structure.

## Social data limitations

GitHub is queried directly from its public API. Instagram and LinkedIn are represented as profile links rather than scraped client-side data. A later API integration can populate those cards without changing the page structure.
