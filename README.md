# Shree Sawariya Agro Agency

Build and operate a production-grade agriculture shop management and e-commerce system for **Shree Sawariya Agro Agency**.

This project contains the admin panel, storefront foundation, theme system, reusable UI components, Supabase-backed shop data, authentication, and navigation structure for future expansion.

## Tech stack

- TypeScript
- React
- Vite
- Tailwind CSS
- shadcn/ui
- TanStack Router
- TanStack Query
- React Hook Form
- Zod
- Framer Motion / Motion
- Recharts
- Supabase

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

The application branding and document title are set to **Shree Sawariya Agro Agency**.
